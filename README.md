# Шахматы 13×13

Одна страница (index.html), работает офлайн как PWA. Онлайн-игра идёт напрямую между игроками (WebRTC, PeerJS), свой сервер не нужен.

## Выложить на GitHub Pages
1. Создай репозиторий, загрузи все файлы из этой папки.
2. Settings → Pages → Branch: main, папка / (root).
3. Через минуту сайт будет на https://ИМЯ.github.io/РЕПО/ (это HTTPS, как нужно для Telegram).

## Telegram (Mini App)
1. В @BotFather: /newbot, создай бота.
2. /newapp → выбери бота → вставь ссылку на GitHub Pages. Получишь ссылку вида t.me/бот/приложение.
3. Или /setmenubutton → ссылка: кнопка меню в чате с ботом откроет игру.

## Google Play
Открой https://www.pwabuilder.com, вставь ссылку на сайт, нажми Package for stores → Android. Нужен аккаунт разработчика Google Play ($25 разово).

## Онлайн
Оба игрока вводят один код комнаты, первый пришедший играет белыми. Если нужен рейтинг для всех и поиск соперника, понадобится свой сервер.

## Обычное приложение на Android (APK)
1. Загрузи все файлы папки в репозиторий GitHub (вместе с папкой .github).
2. Открой вкладку Actions → Build APK → дождись зелёной галочки (3–6 минут).
3. Внутри запуска внизу скачай архив chess13-apk, в нём app-debug.apk.
4. Отправь APK в Telegram-канал или друзьям. Установка: открыть файл и разрешить установку из неизвестных источников. Иконка появится на рабочем столе.

APK тестовый (debug), подходит для раздачи напрямую. Для Google Play нужен подписанный AAB: проще всего через pwabuilder.com.

## iPhone
Файлом не раздать. Открой сайт в Safari → Поделиться → На экран «Домой»: появится иконка, игра откроется на весь экран.
